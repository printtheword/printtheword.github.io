Keine Cookies, kein Tracking

Diese Website verwendet keine Cookies, keine Analyse- oder Tracking-Werkzeuge und bindet keine Inhalte von Drittanbietern ein. Bibeltexte, Schriften und das Satzprogramm werden von derselben Adresse geladen wie die Website selbst.

Verarbeitung im Browser

Die eingegebene Bibelstelle und die Layout-Einstellungen werden ausschließlich in deinem Browser verarbeitet. Auch das PDF wird lokal in deinem Browser erzeugt; es werden keine Eingaben an einen Server übermittelt. Damit deine Einstellungen und die zuletzt verwendeten Bibelstellen beim nächsten Besuch wieder da sind, werden sie im lokalen Speicher (localStorage) deines Browsers abgelegt. Diese Daten verlassen dein Gerät nicht und können jederzeit über die Browser-Einstellungen („Websitedaten löschen“) entfernt werden. Wenn du einen Link über „Link teilen“ weitergibst, enthält dieser die Bibelstelle und die Einstellungen.
